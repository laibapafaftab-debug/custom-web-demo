# AuraStudio — Websites & AI Automation

Web apps and AI automation, built and deployed by Laiba Aftab.

**Live site:** https://laibapafaftab-debug.github.io/custom-web-demo/

## What this is

A single-page marketing/portfolio site for AuraStudio, presenting web development and AI automation services for small businesses and founders — pricing, process, services, and a working contact form.

## What's on the page

- Hero introduction with core offer
- About: what AuraStudio does differently
- Services: custom websites, AI workflow automation, UI/UX, performance, API integrations, deployment
- Process: a simple 4-step flow from discovery to launch
- Selected work: sample project categories
- Pricing: starter, professional, and automation packages
- Contact form (via [FormSubmit](https://formsubmit.co)) that emails inquiries directly to laibapafaftab@gmail.com

## Stack

- HTML + [Tailwind CSS](https://tailwindcss.com) (via CDN, no build step)
- Google Fonts: Plus Jakarta Sans
- Font Awesome icons
- Contact form powered by FormSubmit (no backend required)
- Hosted on GitHub Pages

## Editing this site

Everything lives in a single `index.html` file with Tailwind loaded from a CDN, so there's nothing to install or build. To make changes:

1. Edit `index.html` directly (in GitHub's web editor, or clone the repo locally).
2. Commit the change.
3. GitHub Pages redeploys automatically within a minute or two.
